# Capybara Admin Frontend

React/Vite custom admin frontend with Dashboard, Products, Add/Edit Product, Categories, Banners, Orders, Order Details, Inventory and Login screens.

Run:

npm install
npm run dev

The UI currently uses mock data. Existing Django API helpers are in `src/services/api.js` and use `VITE_API_URL` (default `http://127.0.0.1:8000/api`). Connect each page to the existing endpoints after the UI is approved.
